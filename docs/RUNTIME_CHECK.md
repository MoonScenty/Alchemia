# 게임 안에서 확인할 것

게임 테스트(628개)는 전용 서버 혼자서 규칙과 수치만 본다. 아래는 게임을 띄워야만 보이는 것들이다: 화면, 소리, 조작, 렌더, 세계의 모양, 두 사람 사이 동기화.

확인한 줄은 체크한다. 원본과 어긋나면 그 줄 밑에 적어 둔다. 원본과 다르게 둔 것은 맨 아래 "버그가 아닌 것"에 모아 두었다.

## 0. 켜기 전후

- [ ] 원본 jar 두 개를 빼고 켜면 `MissingJarsScreen`이 뜬다. 넣고 다시 켜면 뜨지 않는다.
- [ ] 원본 에셋 리소스팩이 켜져 있다. 로그에 빠진 텍스처·모델·소리 경고가 없다.
- [ ] 로그에 레시피·태그·전리품 표·연구 데이터를 읽다 난 오류가 없다.
- [ ] 전용 서버를 띄우고 클라이언트로 접속해도 튕기지 않는다.

## 1. 이번 2차 대조에서 바꿨는데 아직 화면으로 못 본 것

- **Infusion Matrix**
  - [ ] 제단을 세울 때 matrix와 기둥 여덟 칸에 보라 연기가 난다.
  - [ ] 일하는 동안 불안정성이 높을수록 matrix에서 땅으로 번개 호가 자주 친다.
  - [ ] 에센시아 흐름이 matrix 바로 아래 칸에서 끝난다.
  - [ ] 사고로 아이템이 튕길 때 받침대에 연기가 나고 matrix에서 받침대로 호가 간다.
  - [ ] 일이 끝나면 받침대에 보라 연기가 난다.
  - [ ] 플럭스 사고가 나면 받침대에 오염 입자가 오른다.
  - [ ] Goggles of Revealing으로 matrix를 보면 아직 마셔야 할 에센시아가 뜬다.
- [ ] **Essentia Mirror**: 건너편 단지에서 짝 거울로 흐름이 그려진다.
- **포커스 바퀴**
  - [ ] 바퀴 크기와 반투명 회색 고리가 원본 크기·색과 같다.
  - [ ] 같은 포커스가 여럿이어도 한 번만 나온다.
  - [ ] 가운데에 마우스를 두면 툴팁이 뜬다.
- **나무**
  - [ ] Greatwood가 2×2 몸통 두 층이고 위층 잎이 넓다.
  - [ ] Big Magic Tree는 층마다 가지가 2~4개다.
  - [ ] 두 나무 모두 가지 끝 잎이 저절로 사라지지 않는다.
- [ ] **Hand Mirror**: 알림이 채팅창에 뜨고 차원이 이름으로 나온다.
- [ ] **포탑**: 주인이 웅크리거나 Name Tag를 들고 눌러도 포탑 화면이 열린다.

## 4. 조작

- [ ] 기본 키가 다른 키와 겹치지 않는다:
  - 포커스 바꾸기: V
  - 도구 설정: G
  - 하네스: H
- 포커스 바꾸기 키(V)
  - [ ] 짧게 누르면 다음 포커스로 넘어간다.
  - [ ] 누르고 있으면 바퀴가 열리고, 떼면 고른다.
- [ ] 완드를 쥐고 시전하면 쿨다운 동안 아이템이 회색으로 식는다.
- [ ] Thaumostatic Harness: H로 켜고 끈다. 크리에이티브처럼 날고, 달리면 빨라진다. 끄고 떨어져도 낙하 피해가 줄어든다.

## 10. 두 사람이 함께

전용 서버에 두 클라이언트로 들어가 본다.

- [ ] 연구·지식·뒤틀림이 각자에게 맞게 보인다.
- [ ] 같은 화면(Pech, 장치)을 둘이 동시에 열어도 칸이 꼬이지 않는다.
- [ ] 남이 쓴 주문·주입·골렘의 파티클이 다른 사람에게도 보인다.

## 버그가 아닌 것 (원본과 다르게 둔 것)

화면에서 보고 버그로 적지 않도록 모았다. 자세한 까닭은 계획서 각 단계의 "원본과 다른 점"에 있다.

- 주입 중 룬 입자와 후광이 없다. 아이템이 부서질 때 흐름도 없다.
- 충격 포커스는 완드에서 표적까지 긋는 호 없이 맞은 자리의 불꽃만 낸다.
- 갈고리와 Pech 저주는 모형 없이 파티클 자취만 남긴다.
- Pech·포탑 화면은 8칸 밖에서 닫힌다.
- 골렘 순위가 오르면 체력·공격력이 바로 오른다.
- 안정화 블록에 양초와 피글린·드래곤 머리가 든다.
- 발견하지 못한 상은 물음표로 가린다.
